一、问题

改变物距 u，凸透镜所成像的大小、正倒、虚实会怎样变化？规律与焦距 f 有什么关系？

二、猜想

反射角等于入射角（r = i）

三、方案

实验器材：凸透镜、光具座（或刻度尺）、蜡烛（发光体）、光屏

变量控制：

自变量：物距 u
因变量：像距 v、像的大小 / 正倒 / 虚实
控制变量：凸透镜的焦距 f、烛焰高度、光屏位置、三者共轴

实验步骤：

  1. 把凸透镜固定在光具座中间，读出它的焦距 f。
  2. 把发光体放在 u > 2f 处，移动光屏直到出现清晰的像，记录 u、v 和像的性质。
  3. 依次把物距调整为 u = 2f、f < u < 2f、u < f，分别记录成像情况。
  4. 比较各组中 u 与 f 的大小关系 → 像的性质，归纳规律。

五、结论

凸透镜成像规律：u > 2f 成倒立、缩小的实像（f < v < 2f）；u = 2f 成倒立、等大的实像；f < u < 2f 成倒立、放大的实像（v > 2f）；u < f 成正立、放大的虚像（放大镜原理）。

📊 本次共记录 1 组（f ≈ 11 cm）。实测组合：f < u < 2f → 倒立·放大·实像。

💡 口诀：一倍焦距分虚实，二倍焦距分大小；物距减小，像距增大、像变大。
