# 光学交互实验室

> 初中物理光学虚拟实验室 · 单文件 HTML 交互应用
> 适配苏科版八年级上册第三、四章（光的传播、光的折射）

一个**零依赖、双击即用**的初中物理光学虚拟实验室。把光的直线传播、光的反射定律、平面镜成像、凸透镜成像等八个光学实验做成可拖拽、可调参、可测量的交互实验，配合 AI 学伴覆盖苏科版教材光学全章节。

---

## 🧪 包含的实验

1. **光的直线传播** — 影子的形成与长度变化，探究影子与光源、光屏距离的关系
2. **光的反射定律** — 可调入射角，观察反射角变化，验证三线共面与反射角等于入射角
3. **平面镜成像** — 3D 场景自由视角，像与物大小相等、左右相反，支持多点共线判断
4. **光的折射与综合** — 光从空气斜射入水/玻璃，探究折射角变化规律
5. **凸透镜成像** — 完整光路追迹，成像情况随 u 与 f 关系自动切换（倒立实像 / 正立虚像 / 不成像）
6. **光的色散** — 三棱镜分解白光，红橙黄绿蓝靛紫七色可调
7. **小孔成像** — 物距与孔距变化 → 成像倒立程度与亮度变化
8. **影子的形成** — 多盏灯比较影子叠加，探究影子的形成条件

## 🔧 技术要点

- **纯前端单文件**：HTML + CSS + 原生 JS，无构建工具、无 npm 依赖
- **3D 渲染**：自研轻量 3D 场景引擎，支持轨道控制与自由视角
- **物理计算**：薄透镜公式 `1/f = 1/u + 1/v`、折射定律、反射定律均为实时求解
- **AI 接入**：浏览器直连大模型 API（CORS 友好），Key 仅存 localStorage，不上传服务器
- **隐私**：学情数据仅存浏览器本地，可随时清除
- **适配**：自动识别手机 / 桌面，手机竖屏四档断点排版、弹窗全屏化与安全区适配

## 🤖 AI 能力说明

支持接入多家主流大模型（智谱 GLM、DeepSeek、豆包、Kimi 等），用于：

- **AI 学伴**：针对当前实验参数讲解原理、追问概念
- **错题诊断**：根据学生操作数据定位概念误区，给出针对性提示
- **挑战判卷**：自动批改并生成订正建议
- **报告生成**：把实验数据整理成结构化报告文本

API Key 由使用者自行填写，仅保存在本地浏览器，不会上传。
